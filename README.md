# 🥔 Stoemp

Repas de saison de la semaine, liste de courses avec les prix réels des magasins, stock de la maison et prédiction des rachats — pour plusieurs foyers.

- **Appli** : https://stoemp-app.web.app (recommandé pour l'installer sur iPhone) · GitHub Pages : https://qtheun27.github.io/Stoemp/
- PWA installable, hors ligne avec les dernières données, mode sombre, mise en page mobile / tablette / ordinateur.

## Fonctionnalités
- **Semaine** : 7 ou 14 repas, options combinables (saison, région, bio, végé, budget, temps, allergies, ingrédients à éviter, favoris, IA, écouler le stock), remplacement, favoris, version végé par repas, fiche recette, mode cuisine, coût par personne, « Cuisiné » qui déduit le stock.
- **Courses** : besoins des repas − stock + ruptures prévues + ajouts libres (« 2 l de lait »), rangement par rayon appris, « Tu achètes souvent », vue par magasin et meilleure combinaison de 2 enseignes, prix payé, partage.
- **Stock** : par emplacement, péremption, mise en place rapide, −1 / fini / jeté, alertes « bientôt périmé » avec idée de repas.
- **Prédiction** : rythme pondéré des derniers achats, corrigé par les sorties et par « on en consomme plus/moins ».
- **Prix** : robot Renmans hebdomadaire, connecteurs Colruyt / Delhaize / Carrefour / AH (au mieux), capteur « 📥 Envoyer à Stoemp », photo du ticket de caisse lue par Claude.
- **Foyers** : création, invitation par lien, rôles admin / membre, plusieurs foyers par personne.

Voir `CLAUDE.md` pour l'architecture et les commandes.
